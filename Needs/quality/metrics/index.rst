Quality Metrics
==================

Intended to hold traceability and defect metrics for this repo — for
example, orphan-need count (see ``needs_overview``'s "Unlinked (orphan)
needs" table pattern), the known ``SYS_001`` dead link in ``FEAT_A_001``
and ``FEAT_Z_001``, and requirement-review coverage once
``reviews/`` has real entries.

No metrics have been computed yet. This is scaffolding, not a report of
metrics that already exist.
